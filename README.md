# moonlit-bay-trip · 月满湾区

「月满湾区 · 四人之行」中秋出行展示网页——四人两队情侣、三座城市、一轮满月。

- **行程**：广州（9.24–9.25，中秋正日）→ 珠海（9.26–9.27）→ 顺德（9.27–9.28）
- **叙事主线**：月亮一路随行——月相进度条随滚动逐日演变，2026-09-25 满月为全站情绪顶点
- **状态**：已实现完整单页 v1（M1–M4 全量），插画为占位图位（SLOT 标记），待行程后替换为四人实拍

## 技术路线

原生 HTML/CSS/JS 单页，无框架无构建；`data-city` 属性切换三城主题（广州暖金 / 珠海海蓝 / 顺德食色）；移动端优先（微信分享场景）。

```text
moonlit-bay-trip/
├── index.html          # 语义化结构（M1 落地）
├── css/
│   ├── tokens.css      # 设计 Token（CSS 自定义属性）
│   ├── base.css        # 重置/排版/主题切换
│   └── components.css  # 组件样式
├── js/
│   ├── data.js         # 行程数据（唯一数据源，行程微调只改这里）
│   └── main.js         # IO 渐入 / 月相进度 / 灯箱 / 主题切换
└── assets/img/         # gz-/zh-/sd- 前缀命名 + slot 编号
```
